# daily-brief

Create today's shared working brief using `period-brief` with exactly `1` day. Do not ask the user to choose a period or override it from configuration.

The brief can combine recent note changes, active projects, new email, and weather when relevant sources and integrations are available. Follow `period-brief` for date range, setup, source limits, output format, and safety. Missing integrations are reported; never imply data was checked when it was unavailable.
