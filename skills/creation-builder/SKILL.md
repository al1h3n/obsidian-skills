# creation-builder

Build the creation section of a vault map. Explain how to create notes; do not create or alter source notes.

## Steps
1. Inspect only the requested vault scope and relevant template, index, or instruction notes. Skip `.obsidian/`, `.trash/`, and `AI System/` as source material.
2. Record supported note types, template paths, required frontmatter, headings, naming rules, link conventions, and examples.
3. Cite exact vault-relative paths. Separate explicit rules from inferred patterns; label uncertainty.
4. Do not invent missing standards. Ask when a required choice cannot be resolved.
5. Write `<vault>/AI System/Vault Map/creation.md`. If that file exists, create a review copy instead of replacing it.
6. Report the output path and gaps requiring user input.
