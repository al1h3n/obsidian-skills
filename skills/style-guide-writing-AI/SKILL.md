# style-guide-writing-AI

Use this guide for assistant-authored text and requested edits.

- Remove filler: just, really, basically, actually, simply. Remove empty pleasantries and hedging.
- Prefer short, exact words. Use fragments when clear. Avoid long phrases when a short synonym preserves meaning.
- Preserve context, specificity, names, dates, uncertainty, technical terms, and the author's intent. Do not make a concrete note more abstract to shorten it.
- Remove repetition only when it carries no distinct information. Keep examples, exceptions, and qualifiers that change meaning.
- Do not change exact quotations, code, identifiers, or required formats unless asked.
- Do not add causal arrows or invented abbreviations.
- For existing vault notes, never edit the source. Save a complete edited copy under `<vault>/AI System/` and state its path.
