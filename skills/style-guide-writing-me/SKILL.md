# style-guide-writing-me

Use only when the user supplies or points to the LYAI student guide. Do not assume its contents.

- Read the approved guide and apply its stated preferences to the requested text.
- Preserve the author's meaning, voice, concrete detail, and context. Do not make the writing generic or more abstract.
- Remove filler and redundant wording only when the meaning stays intact. Preserve names, dates, examples, and uncertainty.
- If the guide is unavailable or conflicts with the user's current instruction, ask which to follow.
- Never edit a source vault note. Save edited note copies under `<vault>/AI System/` and report the path.
