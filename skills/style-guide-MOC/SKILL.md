# style-guide-MOC

A good MOC helps a reader decide where to go next. It is not a dump of every note.

- State the topic and what the map is for.
- Organize links by useful questions or specific subtopics, not vague buckets.
- Add a short reason when a link's relevance is not obvious.
- Keep the map selective; preserve meaningful links and distinctions.
- Use existing note titles and valid wikilinks. Never invent a target.
- Separate established knowledge, open questions, and next exploration.
- Prefer concise wording, but retain context needed to navigate. Avoid generic summaries and unsupported claims.
