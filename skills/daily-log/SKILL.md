# daily-log

Append a factual activity section to today's daily log using available Cowork session records and authorized Ideaverse file-change data.

## Rules
- Use only data available through authorized tools. Do not imply access to sessions, file histories, or integrations that are unavailable.
- Verify today's date using the environment's date source; use the vault's established daily-note path and format when discoverable.
- Include timestamps, source, and concise activity details. Distinguish observed changes from inferred context.
- Avoid duplicate entries by checking today's existing log first. Do not copy secrets or unrelated content.
- Never edit an existing user note. Write the proposed complete log or append as a review copy under `<vault>/AI System/`, preserving the original relative path.
- If today's note cannot be identified, ask or report the missing path.
