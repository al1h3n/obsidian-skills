# sherpa

Help the user map a topic they want to explore. Load `style-guide-MOC` and follow it.

## Steps
1. Ask focused, open questions about scope, purpose, audience, prior knowledge, key questions, and useful connections. Ask a small batch at a time; skip questions already answered.
2. Use only the user's answers and approved vault material. Preserve their terminology and voice; do not fabricate conclusions or citations.
3. Draft a navigable starter MOC with a clear title, purpose, sections, key questions, and relevant existing wikilinks. Mark unknowns as questions.
4. Keep language concrete and concise. Remove filler without removing context or making the map generic.
5. Never edit source notes. Save the draft to `<vault>/AI System/MOCs/<topic>.md`; avoid overwriting by choosing a distinct review filename.
6. Show the path and invite corrections to the map, not unsolicited expansion.
